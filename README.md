
# 3D AI-Powered T-Shirt Generator   

A real-time 3D T-shirt customization platform that lets users upload their own logos/images or generate brand-new designs using DALL·E AI, and instantly visualize them on a fully interactive Three.js model.


## ❓ Problem Statement

Custom merchandise design often lacks instant visualization. Users struggle to imagine how a logo or artwork will look on a real product. Traditional tools are either static, slow, or require manual editing skills.


## 💡 Solution

This project bridges 3D rendering + AI image generation to deliver an interactive and creative design playground:

- 🌀 Live 3D T-shirt preview with drag/zoom controls

- 🖼️ Upload any logo or artwork and instantly apply it

- 🎨 Generate AI-based design elements using DALL·E

- 🔄 Switch between colors, placements & text overlays

- ☁️ Backend-powered storage & design persistence


## 🗺️ Key Features

| Feature                 | Description                                                             |
| ----------------------- | ----------------------------------------------------------------------- |
| 🧭 3D Real-Time Preview | Built with **Three.js**, allowing rotation, zoom & pan of the T-shirt   |
| 🖼️ Logo/Image Upload   | Upload custom PNG/JPEG logos and place them freely on the T-shirt       |
| 🤖 AI Design Generator  | Use **DALL·E** to generate unique logos, patterns, or full-shirt prints |
| 🎨 Color Customization  | Change T-shirt fabric color dynamically                                 |
| 💾 Backend Integration  | Powered by **Node.js/Express** for API routes and image processing      |
| 📤 Export / Save Design | (Optional) Export as PNG or save design metadata                        |



## ⚙️ Tech

| Layer                  | Technologies                               |
| ---------------------- | ------------------------------------------ |
